# IMAGE GUIDE

You only need **8 core images** for the entire website. I have removed all the unnecessary clutter.

Whenever you want to replace an image on the website, just overwrite the specific `.jpg` file in the folder structure below with your own photograph.

## Where to put your images:

```text
public/
└── images/
    ├── profile/
    │   └── profile-main.jpg                  ← Your main headshot/photo
    │
    ├── internships/
    │   ├── atul-jain/
    │   │   └── research-main.jpg             ← Auxetic structures/3D printing photo
    │   └── sikha-hota/
    │       └── research-main.jpg             ← Missile guidance/trajectory photo
    │
    ├── projects/
    │   ├── mapathon/
    │   │   └── project-main.jpg              ← Flood map photo
    │   ├── fixed-wing-aircraft/
    │   │   └── project-main.jpg              ← Aircraft photo
    │   └── aerial-robotics-analysis/
    │       └── project-main.jpg              ← ANSYS simulation screenshot
    │
    └── engagements/
        ├── aerial-robotics-kharagpur.jpg     ← ARK team/drone photo
        └── ncc-air-wing.jpg                  ← NCC uniform/parade photo
```

### Tips for your real images:
* **Format:** Use `.jpg` or `.jpeg` files (just rename the extension to `.jpg` so it matches).
* **Shape:** `profile-main.jpg` looks best if it's slightly taller (portrait). Everything else looks best if it's wider (landscape, like a desktop wallpaper).
* **Size:** Try to keep them under 500KB so your website loads fast.
