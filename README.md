# Rajdip Kundu — Aerospace Engineering Portfolio

A cinematic, single-page personal portfolio for **Rajdip Kundu**, an Aerospace Engineering student at IIT Kharagpur.

The portfolio is designed around an aerospace/engineering visual identity and begins with a cinematic 3D rocket-launch experience that transitions into the portfolio.

---

## 1. Portfolio Vision

The website should feel like a premium aerospace engineering portfolio rather than a generic student portfolio.

### Core visual identity

- Dark, cinematic interface
- Aerospace-inspired visual language
- Subtle technical/HUD elements
- Clean typography
- Controlled glow and atmospheric effects
- Smooth section transitions
- Responsive design
- Strong emphasis on projects, research and engineering

### Main opening experience

The landing sequence follows:

**Launch Pad → Ignition → Exhaust/Smoke → Rocket Launch → Smoke Dissipation → Rajdip Kundu Portfolio Reveal**

The rocket sequence should be immersive, but the portfolio itself must remain fast, readable and maintainable.

# 6. Hero / Rocket Experience

The hero is the signature element of the website.

## Sequence

### Stage 1 — Darkness

Begin with a dark environment.

Only subtle atmospheric details should be visible.

### Stage 2 — Launch Pad

Reveal:

- Rocket
- Launch pad
- Support structure
- Ground
- Atmospheric haze
- Subtle lighting

### Stage 3 — Ignition

Introduce:

- Engine glow
- Heat/light
- Initial exhaust
- Smoke
- Particles

### Stage 4 — Launch

The rocket lifts off.

Increase:

- Exhaust
- Smoke
- Particles
- Light
- Camera movement

### Stage 5 — Transition

As the rocket moves away:

- Smoke remains in the scene
- Smoke gradually disperses
- Background remains dark
- Portfolio UI begins appearing
- Name appears
- Professional introduction appears
- Navigation becomes visible

The transition should feel continuous.

Avoid a hard cut between the rocket and portfolio.
